# Reference Work

Make the work answer its brief. Use references to see possibilities you would otherwise miss, then build and judge an actual result. Preserve the user's content, audience, constraints, chosen direction, and existing project identity. A small extension usually needs continuity more than a new concept.

## Find a useful reference

Name the unresolved decision in concrete terms: how information unfolds, what carries emphasis, how parts join, what an action feels like, how a passage changes pace. Search for that property and the task's real subject. The bundled catalog is a starting library; widen to live primary collections, original publications, maker documentation, recordings, or working examples when it cannot answer the question. Use available browser/search tools and record discoveries with the CLI. No service or API key is required.

Browse [collection routes](references/collections.json) with `python3 scripts/reference.py sources "<subject>" --project <stable-project-id>`; omit the query for a broader route list. Search works with `python3 scripts/reference.py search "<property or subject>" --project <stable-project-id>`. Run from this skill's folder or use the absolute script path. Results match words, then reduce creator, family, collection, and repeatedly discovered neighborhood concentration. They carry provenance, never taste scores. Follow relevant results beyond the most familiar medium or maker without sacrificing task fit. The same project may continue using its sources; unrelated projects exclude previously selected works unless you state a specific reuse reason.

## Inspect before borrowing

Read, view, listen to, or operate the source itself. A title, search snippet, museum description, or attractive thumbnail can support discovery but cannot establish unobserved craft or behavior. Use the source's actual scale and sequence where it matters. Bundled inspection notes describe only the portion and modality recorded. Reinspect anything the new decision depends on. Record concrete observed properties and limits with `inspect`; record broken and blocked sources accurately. See [library.md](references/library.md) for commands, identity, dates, and rights.

Link **source property → application to this brief → concrete adaptation**. Explain the mechanism: what the source does, why that helps this audience, and what changes in the new material or context. Keep attribution distinct from inference. Copying a recognizable motif does not establish that its organizing principle survived. See [translation.md](references/translation.md) when crossing media or when references are becoming cosmetic.

## Make and compare

Build the smallest representative part that can settle the consequential choice, then carry the chosen logic through the finished work. Depending on the brief, this may be a paragraph, joint, page spread, exchange, scene, transition, or working control. Compare meaningful alternatives when uncertainty justifies them; the number and format are yours to choose. Record adopted sources with `select` and the property, application, and actual adaptation.

Judge the result against the brief and the source's relevant discipline. Identify the visible or experienced part that succeeds or fails, revise the cause, and inspect the result again. Do not equate reference quantity, novelty, polish, or a passing build with quality. Preserve necessary convention and user-requested familiarity. Read only the relevant portions of [review.md](references/review.md) for medium-specific evidence. Finish the requested artifact and report meaningful remaining limits; keep research bookkeeping outside the audience-facing work.
